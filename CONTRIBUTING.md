# Contributing

- **Issues are welcome:** bug reports, questions and feature ideas. Use the issue forms.
- **Pull requests are by invitation.** Please open an issue first and wait for an invitation before you write code. Pull requests sent without one may be closed unread.
- **Vulnerabilities:** report them privately, as described in [SECURITY.md](SECURITY.md).
- **Commits** follow [Conventional Commits](https://www.conventionalcommits.org/) with the plugin as the scope, e.g. `fix(guard-hooks): ...`. Each plugin's version and changelog come from them.
